\cvsection{Open Source}

\begin{cvlistsection}

\item \textbf{MochaChat} \href{https://github.com/2ufiq/mocha-chat}{\faGithub}  \href{https://mocha-chat.onrender.com/}{\textcolor{Cerulean}{\faExternalLink*}}\\
Multi-character AI companion with streaming conversations. Built stateless FastAPI backend with browser-local per-character memory, streaming responses, LLM memory compaction, multilingual support, and cheap LLM routing via OpenRouter.\\
\textbf{Tools:} FastAPI, OpenRouter, Render

\item \textbf{Python Buddy} \href{https://github.com/2ufiq/slm-python-buddy}{\faGithub}\\
Fine-tuned a small language model (Qwen2.5-coder-1.5-instruct) for code assistance, worked on low-resource training and inference. Achieved ~7–12 tokens/s inference speed with 8-bit quantization on Snapdragon 685.\\
\textbf{Tools:} HuggingFace Transformers, Llama.cpp, Python

\item \textbf{Inference API Server} \href{https://github.com/2ufiq/slm-api-server}{\faGithub}\\
Developed a lightweight Python API server for local/self-hosted LLM inference. Supports GGUF models with both string-based and role-based prompts, returns OpenAI-compatible responses.\\
\textbf{Tools:} Python, HuggingFace Hub, Llama-cpp-Python

\item \textbf{Blood Cancer Stage Detection App} \href{https://github.com/2ufiq/Vision-Blood-Cancer-Stage-Detection}{\faGithub}\\
Built a deep learning web app for acute lymphoblastic leukemia (ALL) stage detection. Finetuned and evaluated 4 CNN architectures; MobileNetV2 achieved 98\% accuracy across 3 leukemia subtypes.\\
\textbf{Tools:} TensorFlow CPU, Flask, OpenCV, Gunicorn, Render

\item \textbf{Chronic Kidney Disease Diagnosis App} \href{https://github.com/2ufiq/ML-Kidney-Disease-Diagnosis}{\faGithub}\\
Built a Flask-based ML app for early chronic kidney disease detection. Used LOF for outlier removal, SMOTE for imbalance handling, and Random Forest achieved maximum accuracy on test data.\\
\textbf{Tools:} Scikit-learn, Flask, Gunicorn, Joblib, Render
